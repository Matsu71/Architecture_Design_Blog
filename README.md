# 建築巡り JAPAN / Architecture Japan Guide

日本の建築を、地図・地域・建築家から探し、見どころと構造・素材を読めるガイドです。最終目標は、日本全国の著名建築や著名建築家の作品を正確な情報で網羅する「世界で一番見やすく、わかりやすい建築まとめサイト」。関東を優先します。

## 現在の内容

2026-09-14品質改善版。関東7都県・13件、静的記事13本、部位・素材の説明24項目、許諾確認済み実写写真2枚を収録しています。全国網羅や全項目の検証完了を意味しません。

地図は建物ごとのピンを表示し、件数クラスタ、座標ずらし、地域中心への仮置きはしません。重なった場合は建物を選んで拡大します。現在は3件について棟の配置と建物輪郭を照合し、10件は施設座標の確認段階です。公開入口は全件未照合です。

検索と地域を常時表示し、建築家・用途・年代・見学・並び順は「絞り込み」にまとめています。日本語変換中は結果を更新せず、確定後に反映します。検索条件と選択した建物はURLに保持します。

記事は建物名、短い特徴、基本情報、見どころ、構造・素材、見学、出典の順。部位ごとの詳細は折りたたみ、記事と地域別一覧はJavaScriptなしでも読めます。竣工と開館、原設計と改修、建築・構造・内装の担当を区別します。

## データと利用条件

- `data/buildings.json`：出典・確認状態を含む編集用正本。
- `data/map-index.json`：本文を除いた地図用データ。記事生成時に更新。
- `articles/`、`catalogue.html`：生成した静的記事と一覧。
- `data/building-footprints.geojson`：採用したOSM由来の輪郭・位置。OpenStreetMap contributors、ODbL 1.0。
- `assets/photos/`：写真とクレジット。今回の2枚はCC BY-SA 3.0。作者・出典・ライセンス・加工内容を画面にも表示。

写真のライセンスは、その画像と改変物に適用します。サイト全体の文章・コード・他の画像に一律適用するものではありません。写真の撮影年は現在の外観や入場条件を保証しません。公式案内図は確認用に閲覧したもので、サイト画像として転載していません。

## 編集と確認

Node.js 20以降。通常のデータ検査・記事生成には追加のnpmパッケージは不要です。

```bash
npm run validate
npm run build:articles
npm test
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。正本を編集したときは、生成された記事・一覧・地図索引・輪郭データも同じ変更に含めます。`npm test` は生成物の一致と写真ハッシュも検査します。

GitHub Pagesは `main / (root)` を標準とし、ビルド不要の公開物を維持します。`file://` ではモジュールとJSON読み込みが動作しないことがあります。

## ブラウザ検証

`tests/browser_integration.py` は本物のLeaflet 1.9.4とローカルHTTPを使い、Chromium・WebKitで実行します。4画面幅、30件重なり、ページ遷移、IMEイベント、写真の読み込みなどを検査します。通常の操作試験では背景タイルを遮断し、タイルの実取得は別試験として記録します。

```bash
python -m pip install playwright==1.55.0
python -m playwright install --with-deps chromium webkit
python tests/browser_integration.py
```

今回の組み立て版はNode 47項目、生成物一致、実ブラウザ142項目に合格し、両ブラウザで背景タイル20枚の取得を確認しました。レポートは `docs/qa/MAP_QUALITY_2026-09-14.json` とActionsの成果物に記録しています。

`Architecture quality` は変更時に検査し、mainでは `tests/public_smoke.py` で公開済みファイルのハッシュを照合したうえで実サイトを確認します。WebKit検査はSafari／iPhone実機試験ではなく、幾何検査も地理・史実の真偽を証明しません。旧 `tests/dom_check.py` は通信・地図を代替する補助検査です。

## 次の優先事項

残りの棟位置と公開入口、庭園美術館本館の単独輪郭の照合、写真の拡充が必要です。美術館以外の駅舎・図書館・学校・邸宅・商業建築等を一次資料で増やし、関東から全国へ広げます。件数の区切りを最終目標の達成にはしません。
