# 建築巡り JAPAN / Architecture Japan Guide

日本の建築を、地図・地域・建築家から探し、見どころと構造・素材を読めるガイドです。最終目標は、日本全国の著名建築や著名建築家の作品を正確な情報で網羅する「世界で一番見やすく、わかりやすい建築まとめサイト」。関東を優先します。

## 現在の実装

2026-09-14継続改修版。関東7都県・13件、静的記事13本、部位・素材の説明22項目を収録しています。全国網羅や全項目の検証完了を意味しません。

- 地図は建物ごとの座標に個別のピンを表示します。件数クラスタ、座標ずらし、地域中心への仮置きはしません。重なった場合は候補を選んで拡大します。
- 地域、建築家、用途、年代、見学条件で絞り込み、建物名・住所・材料などを複数語で検索できます。検索条件と選択した建物をURLに保持します。
- 大画面は地図と一覧を並べ、スマートフォンは切り替えます。地図が取得できない場合も一覧と静的記事を利用できます。
- 記事は建物名、短い特徴、基本情報、見どころ、構造・素材、見学、出典の順です。部位ごとの詳細は折りたたみます。記事と地域別一覧はJavaScriptなしでも読めます。
- 竣工と開館、建築設計と構造・内装、創建と改修を分けて記録します。東京文化会館の改修休館は記事の冒頭と一覧に表示します。

## ファイル

`data/buildings.json` が出典・検証状態を含む正本です。`data/map-index.json` は生成した軽量地図データで、本文・出典一覧は含めません。`articles/` と `catalogue.html` も生成物です。

`assets/` は画面・記事・位置処理、`scripts/` はデータ検査と記事生成、`tests/` は再検証用コードです。`docs/REFERENCE_DESIGN_2026-09-14.md` に参考サイトと採否、`docs/CONTINUATION_AUDIT_2026-09-14.md` に今回の改修と未完了事項を記録しています。編集時は `AGENTS.md` と `DEVELOPMENT_POLICY.md` に従います。

## 確認と公開

Node.js 20以降。Nodeテストと記事生成には追加のnpm依存パッケージはありません。

```bash
npm run validate
npm run build:articles
npm test
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。`file://` ではモジュールとJSON読み込みが動作しないことがあります。

データ変更時は、正本だけでなく生成された地図索引・記事・一覧を同じコミットに含めます。`npm test` は生成物の一致も検査します。GitHub Pagesは `main / (root)` を標準とし、ビルド不要の成果物を維持します。リポジトリの変更と公開ホストへの反映確認は別です。

## テストの範囲

今回の実行結果は、Node 37項目と生成物一致検査、データ検査（13件、エラー0）、オフラインChromium 45項目の合格です。

ブラウザ検査は `python3 tests/dom_check.py`。PythonのPlaywrightとChromiumが必要です。Chromiumのパスは `CHROMIUM` 環境変数で指定でき、既定は `/usr/bin/chromium` です。出力はリポジトリの親ディレクトリの `qa/` に保存します。

このDOM検査は実際のHTML/CSS/アプリ処理を使いますが、Leaflet・通信・URL履歴は明示的な代替実装です。本物の地図タイル、公開ホスト上のナビゲーション、Safari実機、地理的な正確さを検証したものではありません。テストの合格を出典内容の正しさの証明とも扱いません。

## 残っている課題

現在の13件は公開された施設座標と名称・住所の照合段階です。棟の輪郭と公開入口は未照合であり、施設点を入口として保証しません。見学条件は訪問直前の再確認が必要です。写真・図版は利用権確認後に追加します。

次の優先事項は、棟位置の資料照合、本番の地図・端末での確認、関東の未収録建築の出典付き追加、全国への拡張です。件数の区切りを最終目標の達成と扱いません。
