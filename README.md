# 建築巡り JAPAN / Architecture Japan Guide

日本の建築を、地図・地域・建築家から探し、見どころと構造・素材を読めるガイドです。最終目標は、日本全国の著名建築や著名建築家の作品を正確な情報で網羅する「世界で一番見やすく、わかりやすい建築まとめサイト」。関東を優先します。

## 現在の内容

2026-09-14関東拡充版。**関東7都県・20件、静的記事20本、部位・素材の説明38項目、許諾確認済み実写写真2枚**を収録しています。全国網羅や全項目の検証完了を意味しません。

今回追加したのは、東京駅丸の内駅舎、東京カテドラル聖マリア大聖堂、自由学園明日館中央棟、神奈川県立音楽堂、横浜港大さん橋国際客船ターミナル、浅草文化観光センター、国際子ども図書館レンガ棟の7件です。既存13件の正本レコードは変更せず、近くの建築などの生成表示を更新しました。

地図は建物ごとのピンを表示し、件数クラスタ、座標ずらし、地域中心への仮置きはしません。重なった場合は建物を選んで拡大します。現在は3件について棟の配置と建物輪郭を照合し、17件は施設位置の確認段階です。公開入口は全件未照合です。

検索と地域を常時表示し、建築家・用途・年代・見学・並び順は「絞り込み」にまとめています。旧帝国図書館などの別名でも検索できます。日本語変換中は結果を更新せず、確定後に反映します。検索条件と選択した建物はURLに保持します。

記事は建物名、短い特徴、基本情報、見どころ、構造・素材、見学、出典の順。部位の詳細は折りたたみ、記事と地域別一覧はJavaScriptなしでも読めます。竣工と開館・開校・開業、原設計と改修を区別し、資料により年代が異なる場合は補足を表示します。見学に重要な条件は短い注意書きを冒頭に表示します。

## データと利用条件

- `data/buildings.json`：出典・確認状態を含む編集用正本。
- `data/map-index.json`：本文を除いた地図用データ。記事生成時に更新。
- `articles/`、`catalogue.html`：生成した静的記事と一覧。
- `data/building-footprints.geojson`：前回照合した3件のOSM由来の輪郭・位置。OpenStreetMap contributors、ODbL 1.0。
- `data/additions/kanto-osm-evidence.geojson`：今回採用した6件のOSM由来の施設位置の根拠。上記と同じ利用条件。建物単独の輪郭・入口を検証済みとするデータではありません。
- `assets/photos/`：写真とクレジット。現在の2枚はCC BY-SA 3.0。作者・出典・ライセンス・加工内容を画面にも表示。

写真のライセンスは、その画像と改変物に適用します。サイト全体の文章・コード・他の画像に一律適用するものではありません。撮影年の古い写真は現在の外観や入場条件を保証しません。公式案内図は確認用に閲覧したもので、サイト画像として転載していません。

## 編集と確認

Node.js 20以降。通常のデータ検査・記事生成には追加のnpmパッケージは不要です。

```bash
npm run validate
npm run build:articles
npm test
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。正本を編集したときは、生成された記事・一覧・地図索引・輪郭データも同じ変更に含めます。`npm test` は生成物の一致、写真ハッシュ、出典参照、別名検索、日付の補足と設計役割も検査します。

GitHub Pagesは `main / (root)` を標準とし、ビルド不要の公開物を維持します。`file://` ではモジュールとJSON読み込みが動作しないことがあります。

## ブラウザ検証

`tests/browser_integration.py` は本物のLeaflet 1.9.4とローカルHTTPを使い、Chromium・WebKitで実行します。4画面幅、30件重なり、ページ遷移、IMEイベント、写真、追加記事の補足や見学条件などを検査します。通常の操作試験では背景タイルを遮断し、タイルの実取得は別試験として記録します。

```bash
python -m pip install playwright==1.55.0
python -m playwright install --with-deps chromium webkit
python tests/browser_integration.py
```

今回の組み立て版はNode 60項目、生成物一致、実ブラウザ178項目に合格し、両ブラウザで背景タイル20枚の取得を確認しました。実行記録は `docs/qa/KANTO_EXPANSION_2026-09-14.json` とActions成果物に保存しています。

`Architecture quality` は変更時に検査し、mainでは `tests/public_smoke.py` と `tests/public_content.py` で対象版のファイルを照合して公開サイトを確認します。WebKitはSafari／iPhone実機ではなく、幾何検査も地理・史実の真偽を証明しません。公開確認の結果は当該mainコミットの `public-report.json` と `public-content-report.json` を参照します。

## 移行記録と通常編集の区別

`data/revisions/`、`apply-reviewed-revision.mjs`、`apply-kanto-expansion.mjs`、`apply-kanto-ui.py` は、それぞれ特定の版に対する一度限りの移行記録です。通常の更新では正本を直接編集し、過去の移行を繰り返さないでください。基準データのハッシュが異なるときは自動上書きせず、差分を整理します。

関東拡充用の組み立て処理は、明示した作業ブランチのリクエストでだけ実行します。読み取り権限で生成・検査し、別の限定された書込みジョブで検証済みのファイルだけを同じ作業ブランチにコミットします。mainへの反映は別途行います。

今回の確認内容は `docs/KANTO_EXPANSION_2026-09-14.md`、前回の地図改善は `docs/MAP_QUALITY_2026-09-14.md`、参考構成は `docs/REFERENCE_DESIGN_2026-09-14.md` を参照してください。
