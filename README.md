# Building Architecture Blog

日本の建築を「探す・知る・巡る」ための、建築観光ガイド兼解説メディアです。

> Working title: **建築巡り JAPAN / Architecture Japan Guide**

## 目標

日本の建築を目的に街を歩く人にとって、最も使いやすく、情報量が多く、見やすく、分かりやすく、正確なサービスを目指します。

初期フェーズでは **関東（東京・神奈川・千葉・埼玉・茨城・栃木・群馬）を最優先** とし、現代建築だけでなく、近代建築・歴史建築・保存建築・優れたリノベーションも対象にします。

## このサービスでできること

- 日本地図から建築スポットを探す
- 建築名・建築家・地域・キーワードで検索する
- 時代、用途、見学可否、地域などで絞り込む
- 「なぜ見る価値があるのか」を短時間で理解する
- 詳細ページで建築史・デザイン・構造・素材・見どころを読む
- 建物を構成する要素（基礎、柱・梁、屋根、外壁、開口部、床、内装など）と、それぞれの役割を理解する
- 特徴的な建材・原材料について、種類・産地や由来・加工法・採用理由・構造上／意匠上の役割・経年変化まで知る
- 公開状況、アクセス、見学上の注意を確認する
- 将来的に、周遊ルート・テーマ別コース・自然や観光スポットとの組み合わせを提案する

## 競合に対する基本方針

既存サービスには、建築マップ、専門家向け建築データベース、建築ニュース／作品メディア、期間限定の建築祭ガイドなど、それぞれ強みがあります。本プロジェクトではそれらを単純に模倣せず、以下を一体化します。

1. **発見性** — 地図と検索からすぐに面白い建築へ辿り着ける
2. **観光実用性** — 実際に行けるか、何を見るべきか、近くに何があるかが分かる
3. **解説力** — 初心者にも分かりやすく、必要なら専門的な詳細まで掘れる
4. **網羅性** — 有名作だけでなく、歴史建築・地域建築・保存建築まで扱う
5. **正確性** — 公式・一次資料を優先し、出典と検証状態をデータとして保持する

## 現在のプロトタイプ

このリポジトリは、ビルド不要の静的プロトタイプから開始します。

- `index.html` — 地図・検索・一覧・詳細を備えた初期UI
- `assets/styles.css` — モバイル優先のスタイル
- `assets/app.js` — 検索、絞り込み、Leaflet地図、詳細表示
- `data/buildings.json` — 建築スポットの構造化データ
- `docs/` — 構想、競合調査、データ設計、編集方針、ロードマップ

ローカルでは簡易HTTPサーバーで確認できます。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## データ方針

建物データには、表示用情報だけでなく、検証のためのメタデータを持たせます。

- 公式名称
- 緯度・経度
- 都道府県・市区町村
- 竣工年・時代区分
- 建築家／設計組織
- 用途・様式・構造・主要素材
- 建物の構成要素（基礎、柱・梁、屋根、外壁、開口部、床、内装など）
- 特徴的な建材・原材料の詳細（樹種・石種等、産地／由来、使用部位、加工・施工法、採用理由、構造・意匠上の役割、経年変化、保存・補修上の特徴）
- 見どころ
- 一般向け短文解説
- 専門向け詳細解説
- 見学可否・外観見学可否
- 公式URL
- 出典URL群
- 最終検証日
- 検証ステータス

材料情報は、すべての建築で無理に詳細化するのではなく、建築の理解に重要な特徴がある場合に重点的に記録します。見た目だけから樹種・石種・製法・産地などを推測せず、公式資料・文化財資料・設計者資料・専門資料で確認できる情報を優先します。

詳しくは [`docs/CONTENT_MODEL.md`](docs/CONTENT_MODEL.md) を参照してください。

## 開発優先順位

1. 関東の代表建築を高品質に整備
2. 地図・検索・絞り込み・詳細ページの完成度向上
3. 建築家、年代、用途、様式、テーマ別の導線追加
4. 周遊ルート機能
5. 全国展開
6. 自然・景観・文化施設などを組み合わせた建築観光機能

## 注意

現在の `data/buildings.json` はUI確認用の初期シードです。掲載件数を増やす際は、`docs/EDITORIAL_POLICY.md` に従って一次情報を優先し、見学情報など変化する情報には必ず確認日を持たせます。
