# 建物の構成要素・建材・原材料の解説方針

## 目的

このサイトでは、建物を外観・歴史・建築家だけで説明するのではなく、「何から、どのように構成されているか」まで理解できることを目指します。

建築を構成する部位や素材に特徴がある場合は、一般向けにも分かる形で、その役割と意味を解説します。

## 1. 建物の構成要素

必要に応じて、以下のような部位を個別に扱います。

- 基礎
- 柱・梁・架構
- 屋根・軒・庇
- 外壁・内壁
- 窓・開口部・建具
- 床・天井
- 階段・吹抜け
- バルコニー・テラス
- 内装仕上げ
- その他、その建築を理解する上で重要な構成要素

単に部位名を列挙するのではなく、可能な場合は「構造上どのような役割を持つか」「外観・空間・意匠にどのような効果を与えているか」まで説明します。

## 2. 建材・原材料

木材、石材、煉瓦、コンクリート、金属、瓦、土、漆喰、ガラスなどについて、その材料自体に特徴がある場合は詳細に扱います。

特に以下の情報を、根拠が確認できる範囲で記録します。

- 材料の種類
- 木材なら樹種、石材なら石種などの具体的分類
- 産地・採取地・製造地・由来
- 使用されている部位
- 加工法・仕上げ方法
- 施工法・組み方
- その材料が選ばれた理由
- 強度・耐久性など構造上の役割
- 色、質感、光沢、表情など意匠上の役割
- 変色、緑青、風化などの経年変化
- 保存、補修、交換、復原に関する特徴
- 当時の流通・調達事情に意味がある場合はその背景

## 3. 情報の深さ

すべての建物ですべての材料項目を埋める必要はありません。

特に以下に該当する場合を重点的に深掘りします。

- 建築の外観や空間を大きく特徴づける材料
- 地域性の強い材料
- 歴史的に珍しい材料
- 技術革新を示す材料
- 建築家の設計思想と強く結び付く材料
- 保存・復原上の重要性が高い材料
- 現地で観察すると面白い材料

## 4. 正確性

樹種、石種、産地、加工法、施工法、採用理由などは、見た目だけから推測しません。

情報源は以下を優先します。

1. 建物・施設・所有者の公式資料
2. 国・自治体・文化財関係資料
3. 建築家・設計事務所の公式資料
4. 保存修理・復原工事報告書
5. 学術論文、大学・研究機関、建築専門誌・専門書

資料で確認できない項目は、無理に補完せず「不明」または未記載とします。

## 5. データモデル案

既存の `materials` は検索・一覧表示用の簡潔な配列として残し、詳細情報は将来的に `components` と `materialDetails` に分離して保持します。

```json
{
  "materials": ["木", "銅板"],
  "components": [
    {
      "type": "roof",
      "nameJa": "大屋根",
      "description": "建物全体を覆う主要な屋根",
      "structuralRole": "荷重を架構へ伝える",
      "designRole": "建物のシルエットを特徴づける",
      "materials": ["銅板"]
    }
  ],
  "materialDetails": [
    {
      "name": "銅板",
      "category": "metal",
      "usedFor": ["屋根"],
      "origin": null,
      "processingMethod": null,
      "selectionReason": null,
      "structuralRole": null,
      "designRole": "表面の質感と経年変化が外観を特徴づける",
      "aging": "酸化による色調変化",
      "conservationNotes": null
    }
  ]
}
```

## 6. 記事での見せ方

一般ユーザー向けの詳細ページでは、専門的な材料情報を最初から大量に表示するのではなく、次の順序を基本とします。

1. 何が特徴的な建物か
2. 現地で注目すべき構成要素
3. その部位が何でできているか
4. なぜその材料・構法が使われたか
5. より専門的な技術・保存情報

これにより、初心者には分かりやすく、興味のある利用者は原材料・構法まで深く読める構成にします。
