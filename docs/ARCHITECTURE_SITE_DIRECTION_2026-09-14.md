# 建築サイトの最終目標・改修方針

更新日：2026-09-14。

## 最終目標

日本全国の著名建築、著名建築家の作品、注目される建築を、正確な情報とともに探せる「世界で一番見やすく、わかりやすい建築まとめサイト」を目指す。現時点の対象は日本、関東を最優先にする。件数の区切りを最終目標の達成と扱わない。

## 優先事項

1. 地図は一つの建物を実際の所在地に対応させる。多数の建物を件数付きの一つの点に集約しない。近接時は候補選択と拡大で解決する。地域中心への仮置き、座標ずらし、同一座標だからという理由でのレコード削除は行わない。
2. 既存のChatGPT製構成を良いものと仮定しない。建築・関連情報サイトを広く比較して参考先を選び、構造・導線・色・余白・文字の階層を一貫した形に統合する。他サイトの文章、写真、図、固有デザインを複製しない。
3. トップは検索と地図・一覧を優先。記事の題名は建物名、見出しは短い具体語。本文以外に長い抽象的な宣伝文や「未来を切り開く」型のコピーを置かない。体言止め等の自然な短い表現を参考にする。本文の必要な情報を一律に削らない。
4. 名称、竣工年、設計者、住所、構造・素材に出典を対応させる。竣工と開館、建築設計と内装・構造設計、創建と改修を混同しない。確認日は実際の資料確認に基づける。
5. 基本情報、施設座標、棟の位置、入口、見学条件の確認状態を分ける。施設座標だけで全項目検証済みと表示しない。材料の種類・産地・製法を見た目から推測しない。
6. 建物の構成要素、特徴的な建材・原材料の解説方針を維持する。詳細は必要な人が開ける構成にする。写真は利用権を確認してから追加する。

## この作業セッションの状態

**以下の実装は作業用ファイル内の成果で、公開用コードには未反映。** GitHubへのコード書き込みが安全性チェックでブロックされたため、コードの反映を完了したとは扱わない。この文書は方針と状態を記録するものであり、デプロイ完了の報告ではない。

作業用ファイルでは、数字ピンを廃止した個別位置表示、近接候補選択、検索・一覧中心の構成、関東7都県11件のデータ、11件の静的記事、部位・素材・出典表示、軽量地図索引、データ検査を作成した。Node.jsの23項目と、Chromiumのメモリ内DOM検査40項目が合格した。DOM検査の地図・通信・履歴は明示的な代替実装であり、本番Leafletや公開ホスト、Safari実機の確認ではない。

現行コードの調査では件数クラスタはなく、ピン内の数字は竣工年の下2桁だった。施設の公開座標と公式名称・住所は照合したが、全棟の輪郭・入口照合は未完了。全国網羅、写真の権利確認、本番画面評価も残っている。

改修一式を適用する際は、既存の同時進行変更を確認し、生成済み記事・地図索引も含めて反映する。`npm run validate` と `npm test` を実行し、公開ホストで個別ピン、重なり選択、スマートフォン表示を確認する。
